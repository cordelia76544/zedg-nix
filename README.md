# ZedG Nix Flake

为 [zed-globalization](https://github.com/x6nux/zed-globalization)（Zed 编辑器的中文/全球化构建版）提供开箱即用的 NixOS Flake 支持。


## 快速体验

如果你启用了 Nix Flakes，可以直接在终端运行以下命令来体验（无需安装）：

```bash
nix run github:cordelia76544/zedg-nix#

```
